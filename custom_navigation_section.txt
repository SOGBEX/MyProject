ОБЪЯСНЕНИЕ ИЗМЕНЕНИЙ:

1. Для UIVersion 3 (старая версия SharePoint):
   - Добавлена новая строка таблицы с ссылкой mailto
   - Использована стандартная иконка mail.gif
   - Применены стили, соответствующие другим элементам навигации

2. Для UIVersion 4 (SharePoint 2010):
   - Добавлен новый элемент списка <li>
   - Использована стандартная иконка из fgimg.png (спрайт)
   - Применены стили s4-specialNavIcon для консистентности

3. Ссылка mailto содержит:
   - Получатель: dl-a@s.ru
   - Тема: "Вопросы и предложения" (URL-кодированная)
   - Предзаполненное тело письма с приветствием

АЛЬТЕРНАТИВНЫЙ ВАРИАНТ (если нужна более гибкая настройка):

Если вы хотите добавить JavaScript для более сложной логики формирования письма, можете заменить href на onclick:

onclick="window.location.href='mailto:dl-a@s.ru?subject=' + encodeURIComponent('Вопросы и предложения') + '&body=' + encodeURIComponent('Здравствуйте!\n\nУ меня есть вопрос/предложение:\n\n'); return false;"

Это позволит добавить дополнительную информацию в письмо, например, текущую страницу или пользователя.
